1 How it works

Your website is a set of plain files kept on GitHub (a free, reliable place to store and publish websites). GitHub automatically publishes those files to your public web address. When you change a file, the live site updates itself a minute or two later.

2 Making & publishing edits

The easiest way — no software needed — is to edit right on the GitHub website.

  1. Open the code on GitHub (the button at the top of this page) and sign in.
  2. Click the file you want to change — usually index.html.
  3. Click the pencil ✏️ icon (top-right of the file) to edit.
  4. Use your browser's Find (Ctrl+F / Cmd+F) to jump to the text you want to change. Type over it.
  5. Scroll down, click the green Commit changes button, then Commit again.
  6. Wait 1–2 minutes, then refresh the live site. Done.
Tip: after publishing, do a "hard refresh" so your browser shows the new version, not a cached one — Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).

Prefer a developer workflow? The same edits work through Git:

# clone once, then for each change:
git pull
# edit index.html …
git commit -am "Update prices"
git push   # the live site rebuilds automatically

4 Swap the photos

The site currently uses tasteful stock photography. Replacing it with real photos of your store, staff and press floor is the single biggest upgrade you can make — it makes the site unmistakably yours.

  1. Take (or choose) a photo. Landscape works best for hero, press and rack; upright for couture, fold and fabric.
  2. Rename your photo to exactly the file it replaces — e.g. hero.jpg (all lowercase, ending in .jpg).
  3. On GitHub, open the assets folder → Add file → Upload files → drop your photo in → Commit. A same-named file replaces the old one.

5 Turn on WhatsApp

WhatsApp buttons were left off because your listed number is a landline, and WhatsApp needs a mobile. To add a "WhatsApp Us" button once you have a WhatsApp mobile:

  1. In index.html, find the contact buttons block that contains Call the Store.
  2. Add this line just after it (replace the number with your mobile, in 91 + 10-digit form, no spaces):
<a href="https://wa.me/91XXXXXXXXXX?text=Hi%20Prince%2C%20I'd%20like%20a%20pickup."
   target="_blank" rel="noopener" class="btn btn-ghost">WhatsApp Us ↗</a>
Do not use the landline number for WhatsApp — the link will show an error to customers.

6 Reviews & the enquiry form

Show real reviews

The "Reviews" section shows your true rating and links to your Justdial page — it contains no made-up quotes. To add real customer quotes, copy 2–3 genuine reviews from Google/Justdial into that section (with the customer's first name).

Make the form send you emails

Right now the pickup form asks customers to call to confirm. To receive submissions by email instead, use the free service Formspree:

  1. Create a free Formspree form and copy its form ID (looks like xyzabcd).
  2. In index.html, find your-form-id and replace it with your ID.

That's it — submissions will then arrive in your email inbox.

8 Troubleshooting

My change isn't showing

  • Give it 1–2 minutes after committing — publishing takes a moment.
  • Hard refresh the page (Ctrl+Shift+R / Cmd+Shift+R) to bypass your browser's cache.
  • On GitHub, the Actions tab shows a "pages build and deployment" — a green tick means it published.

A photo is broken / not showing

  • The filename must match exactly, all lowercase, ending .jpg — e.g. hero.jpg, not Hero.JPG.
  • It must be inside the assets folder.

The map is blank

  • The map needs an internet connection to load. If your address changed, update the maps?q=… links (§3).
Golden rule: only change text between the > and < signs (the words people read). Leave the <tags>, quotes and symbols as they are, and the site keeps working.
